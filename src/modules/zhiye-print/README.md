# 知页云打印后端边界

知页打印只复用 practice-hub 的存储和刺猬云印配置。所有接口要求知页独立
AppID 签发的 JWT；`ZHIYE_WECHAT_APPID` 未配置时守卫关闭所有知页业务接口。

## 按量资源保护

- 单份 PDF 最大 50MB、2000 页。
- 每用户每天最多预留 20 份、合计 100MB。额度检查在锁定 `app_user` 行后完成，
  并先写入 `uploading` 草稿，再执行唯一一次对象存储上传。
- 相同用户 24 小时内上传相同 SHA-256 的未下单草稿时直接复用，不再次上传。
- `uploading` 预留 15 分钟后视为失效，允许重新上传，避免进程中断永久锁死草稿。
- 上传失败标记为 `upload_failed`，重试不会静默重复创建有效草稿。
- 预览接口只按 JWT 本人权限签发 course-files 下载地址，不返回数据库中的成本快照。
- 报价没有定时任务。空闲状态为零对象存储和零供应商请求。
- 每个草稿最多创建文件包 3 次、查询文件包 8 次、计算报价 5 次。一次完整
  价格计算固定为打印费和运费各一次，因此供应商请求理论上限为
  `3 + 8 + 5 × 2 = 21` 次/草稿。
- 供应商调用只在用户显式请求报价后发生；报价接口永远不调用供应商下单接口。

生产启用前仍需按实际用户量核对 OSS PUT/存储/CDN、刺猬云印接口及微信支付的
最新计费规则，并配置预算和用量告警。当前代码不会自动启用 worker，也不会在
AppID、支付或供应商配置缺失时降级到 practice-hub 的身份或密钥。
