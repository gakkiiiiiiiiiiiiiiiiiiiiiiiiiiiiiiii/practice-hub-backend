# 刺猬云印对接说明

## 能力边界

- 仅处理 `pay_payload.fulfillment_type = paper` 的已支付纸质资料订单，不会把库存类 `paper_exam` 订单自动送印。
- 管理端支持关闭自动模式后逐单提交；同一业务订单通过 `cloud_print_job.order_id` 唯一键防重复。
- 入队时冻结文件 URL、版本键、页数、顺序、份数和打印配置，后续课程文件变更不会悄悄改变已入队任务。
- 手动下单先计价并展示打印结算价、运费预估和合计，管理员确认后服务端再次计价；价格变化必须重新确认。
- `POST /api/svip/order/generate` 请求无明确响应或返回 5xx 时进入 `review_required`，必须先在刺猬云印后台按业务订单号核对，禁止盲目重试。

## 环境变量

```dotenv
CWY_APPID=
CWY_APPKEY=
CWY_BASE_URL=https://ciweiyunyin.com
CWY_TIMEOUT_MS=15000

# 部署和小批手动验收完成前必须保持 false
CWY_CLOUD_PRINT_WORKER_ENABLED=false
# 推荐设置为高强度随机值，并配置到刺猬云印订单回调 URL 的 token 参数
CWY_CALLBACK_TOKEN=
```

回调地址：`https://你的后端域名/api/app/cloud-print/callback?token=<CWY_CALLBACK_TOKEN>`。回调必须携带该高强度令牌；接口不会接受未鉴权回调。

`calc-ship-price` 文档未标注金额单位，代码按接口示例将 `price` 解释为元并换算成分。真实自动下单前必须用一个小额订单核对供应商后台运费；在确认前保持 worker 和自动模式关闭。单笔打印结算价与运费预估合计还会受管理端“单笔扣款上限”约束。

## 上线顺序

1. 执行 `migrations/create_cloud_print_job_table.sql`，部署后端和管理端，保持自动模式与 worker 关闭。
2. 进入“运营配置 → 云打印”确认密钥状态和默认打印参数。
3. 选一个明确的测试纸质订单，在订单管理中先获取报价，再确认金额并提交；核对文件、页数、份数、地址、供应商订单号、运费单位和余额变化。
4. 配置回调地址；确认运单号可幂等回写订单。
5. 开启 worker，连续观察至少两轮空队列日志为 `scanned=0, attempted=0`，此时云印 API 与对象存储外部请求均为 0。
6. 最后再在管理端开启自动模式。自动订单有 10 分钟缓冲期，便于拦截支付后的异常或售后。

## 请求量与费用估算

每个业务订单正常需要：

```text
1 次创建文件批次 + W 次批次状态查询 + 2 次计价 + 1 次生成订单
```

若每日纸质订单为 `N`，平均等待查询 `W` 次，则自动模式每日云印接口调用量约为 `N × (W + 4)`；手动模式在确认前后各复算一次，会再增加 2 次计价调用。文件只按文件数上传一次 URL，份数通过 `copy` 传递，禁止按份重复上传。另需按源文件总大小评估对象存储外网下行或跨云流出费用；印刷、装订、快递和供应商余额扣款以刺猬云印后台实际计价为准。

## 验收限制

自动化测试只使用 mock，不会拿真实密钥生成订单或扣余额。真实联调必须在管理端二次确认后，用单个小批量订单执行。
